## English

Built from the same code as `/help`: the list, the sections and the sentences are the bot’s own. `/help` answers in the language of the chat; this page holds all three.

### Files and the topic’s project

- `/start` — the welcome card: what this bot is and the three commands to begin with. Telegram sends it when somebody opens the bot.
- `/cd` — Binds the topic to a project folder: /cd my-app. Every turn in the topic then runs there.
- `/ls` — [folder] — lists this topic's folder as buttons, folders first. Press a folder to walk into it, a file to read it. `/ls <file>` opens the file instead.
- `/view` — <file>[:line] — shows a file with line numbers, forty lines at a time, «More» for the next page. `file:412` opens at line 412. Reading only: use /edit to change a file, and /diff to revert one hunk of what a turn changed.
- `/edit` — <file>:<line> — change lines in a file from the chat. You name the lines, send the replacement as the next message, and a diff appears with «Apply» and «Cancel»; the file is written only when you press Apply, and only if its lines still match what the diff showed.
- `/new` — Starts a fresh session in this topic. The old one stays on disk and can be resumed with /sessions <id>.
- `/stop` — Stops the turn that is running in this topic right now (the button under the progress message does the same).
- `/send` — Sends a file from the project into the chat: /send report.pdf.
- `/seed` — Puts the first text into an empty topic and pins it, for topics created before the bot joined.
- `/diff` — What the turn changed in this topic, one hunk at a time. Every hunk gets two buttons: explain it, or revert just that hunk. `/diff stat` is the file list alone.
- `/find` — <text> [path] — searches this topic's folder for a literal string and shows every match as a button; pressing one opens the file at that line. Binary files and files over 512 KB are skipped and counted.

### Goal and tasks

- `/goal` — The goal of this topic in one line: /goal <text>, /goal done. Tasks live under it.
- `/tasks` — The checklist with a button per task: one tap marks it done or undone, and the card is redrawn in place.

### Sessions: status, rewind, copies

- `/status` — Where this topic stands: session, model, effort, running turns. Read-only.
- `/sessions` — The sessions of this topic. /sessions lists the last few with the id to copy; /sessions <id> continues an older one here. /new starts a fresh one and leaves the old on disk.
- `/rewind` — Going back, one command with three words. /rewind 2 removes the last two turns so you can word the task differently: it shows a card of what will go and cuts only on the button; /rewind undo puts it back. /rewind fork [n] copies the session as it stood n turns back and moves this topic onto the copy — nothing is cut. /rewind branches lists the copies, a press switches.
- `/profile` — The profile this topic runs on, and how to change it: /profile <name>, /profile new.
- `/compact` — Where context compaction happens, the threshold this install runs with, and the one thing that works here instead: /new.
- `/card` — The turn card is the message every turn ends with. `/card` opens its rows as buttons: time, speed, thoughts, steps, context, cost, cache, reasoning. The choice is per topic and applies from the next turn.

### Model, prices, fallback

- `/model` — One command for the model of this profile: bare /model draws every route as buttons — provider and model together, because one model name can be served by several endpoints — and /model <provider>/<model> switches without tapping. A tap on the card moves THIS topic; the toggle above the list moves the whole profile at once, and it always says which of the two a tap will do. /model <route> all sets the default every topic follows — that is the one to reach for when an endpoint runs out of money and the fallback chain has to start elsewhere. /model <id> both also sets the desktop profile.
- `/effort` — How hard the model thinks before answering: /effort high.
- `/prices` — Prices of the models in use, and what the current model costs for the tokens this topic has spent.
- `/cost` — What this session has spent: tokens, cache hits and the sum, with the source of the prices named. /cost reads the catalog on disk, /prices is the one that fetches it.
- `/thoughts` — The reasoning behind the last turn: text, file or off.
- `/fallback` — The failover chain: which routes a failed turn switches to, in which order, and what starts a switch. /fallback shows the numbered list with buttons; /fallback test asks each route directly.
- `/endpoint` — The endpoints this profile can reach, and adding one without an AI turn: /endpoint list, /endpoint add <id> <https://url/v1> <KEY_ENV> [model,model], /endpoint rm <id>. Only the name of the variable holding the key is typed — the key stays in the environment. A new model appears on /model as a button.
- `/load` — How busy this computer is: CPU, memory, disk, and how many turn slots the bridge is using. The guard holds a new turn while the machine is over a limit, so somebody else at the same computer is not frozen out.

### Agents and permissions

- `/agents` — Agents and subagents: who is configured, on which model, and who was actually spawned.
- `/crew` — A named bundle of model, permissions and preset for this topic: /crew use <id> switches the whole thing, /crew off goes back to the profile, /crew new|copy|rm and /crew model <v> edit one.
- `/preset` — The agent preset (persona and tools) of the profile: /preset <id>.
- `/plan` — Plan mode for this topic: /plan turns it on or off; the plan comes before any change, then an Approve card.
- `/permissions` — The sandbox and approval preset of the profile.

### Schedules and the queue

- `/jobs` — What the bridge is doing right now: active turns and the queue behind them.
- `/remind` — One reminder: /remind +15m text or /remind 09:30 text.
- `/every` — One repeating schedule: /every 09:00 text runs that text as a normal turn every day at that time. /every list shows this chat's schedules, /every rm 2 removes one. It fires only while the bridge is running; a time that passed while it was down fires once on the next start, not once per missed day.

### Extensions

- `/skills` — Installed skills, or the text of one.
- `/plugins` — The plugin list and the changes: /plugins, /plugins add|remove|disable|enable <id>.
- `/mcp` — The MCP servers of the profile: /mcp as a list, /mcp <name> for one, /mcp add <name> <url> and /mcp rm <name>. The agent calls a server’s tools; the card only names them.
- `/soul` — The persona file of the profile: show or set.

### Bridge versions

- `/update` — Which bridge you run, what npm has, and the mode of update notices: /update, /update on|off|confirm|auto.
- `/subscribe` — Whether this install is announced as a user of the plugin, /subscribe on|off.
- `/dsh` — Which DSH is installed, which one npm publishes, and whether this bridge was tested on it. /dsh update installs the published one; the restart is yours to do.

### Chat switches

- `/settings` — Every switch on one card: the top says what the page is for and what each line means, the buttons underneath are the same list in the same order, and ● marks the value in force. Pages: /settings (answers and the chat), /settings agent (model, effort, permissions), /settings updates (versions), /settings health (checks and logs). A press applies at once and redraws the card; Done removes it.
- `/lang` — The language of the bot in this topic: /lang en|ru|zh.
- `/reasoning` — Working notes: off, in the progress card, or as messages in the chat — /reasoning off|card|chat.
- `/pin` — Holds the progress card pinned while its turn runs, so the clock and the steps are one tap away — /pin on|off.

### Panels and help

- `/menu` — The panel: each job as a button. A press runs the command, the card stays, and the answer arrives under it.
- `/help` — This list. /help <command> explains one command.

### Checks and logs

- `/doctor` — Checks the install: bridge, network, disk, plugins, session. Run it first when something breaks.
- `/logs` — The bridge log: /logs, /logs 100, /logs errors, /logs file.
- `/report` — A bug report assembled from what the bridge already knows and stripped of secrets and home paths before it leaves: /report. In a group it answers with the file path instead of the log.
- `/app` — The DSH desktop app, not the bridge: /app restart confirm.
- `/restart` — Restarts the bridge: /restart confirm. The DSH app is /app.

### Old spellings

These names still work — for a slipped finger or an old habit. /help does not advertise them: one job, one name.

`/models` → `/model` · `/plugin` → `/plugins` · `/agentset` → `/crew` · `/task` → `/tasks` · `/fork` → `/rewind` · `/branches` → `/rewind` · `/resume` → `/sessions` · `/version` → `/update`

Inline: type @bot rew in any chat to see the commands that start with rew. Switch it on once in @BotFather with /setinline — the bot asks Telegram for inline queries only after that.

## Русский

Собрано из того же кода, что и `/help`: список, разделы и пояснения совпадают с ботом. В чате `/help` отвечает на языке темы, а на этой странице — все три языка.

### Файлы и проект темы

- `/start` — приветствие: что это за бот и три команды, с которых начать. Telegram присылает её, когда человек открывает бота.
- `/cd` — Привязывает тему к папке проекта: /cd my-app. Ходы темы идут уже там.
- `/ls` — [папка] — папка темы кнопками, папки сверху. Нажатие на папку заходит внутрь, на файл — открывает. `/ls <файл>` открывает файл сразу.
- `/view` — <файл>[:строка] — файл с номерами строк, по сорок строк, кнопка «Дальше» листает. `файл:412` открывает на строке 412. Только чтение: менять файл — это /edit, а /diff откатывает один кусок того, что изменил ход.
- `/edit` — <файл>:<строка> — править строки файла прямо из чата. Ты называешь строки, следующим сообщением присылаешь новый текст, появляется дифф с кнопками «Применить» и «Отмена». Файл пишется только по нажатию и только если строки всё ещё те же, что были в диффе.
- `/new` — Начинает новую сессию в теме. Старая остаётся на диске, вернуться можно так: /sessions <id>.
- `/stop` — Останавливает ход, который идёт в теме прямо сейчас (кнопка под сообщением о ходе делает то же).
- `/send` — Присылает файл из проекта в чат: /send report.pdf.
- `/seed` — Кладёт первый текст в пустую тему и закрепляет — для тем, созданных до бота.
- `/diff` — Что изменил ход в этом топике, по одному хуну за раз. У каждого хуна две кнопки: объяснить его или откатить только его. `/diff stat` — только список файлов.
- `/find` — <текст> [путь] — ищет в папке темы буквальную строку и показывает совпадения кнопками: нажатие открывает файл на этой строке. Двоичные и слишком большие файлы пропускаются со счётчиком.

### Цель и задачи

- `/goal` — Цель темы одной строкой: /goal <текст>, /goal done. Задачи живут под ней.
- `/tasks` — Список задач кнопками: одно нажатие отмечает задачу выполненной или снимает отметку, карточка перерисовывается на месте.

### Сессии: статус, откат, копии

- `/status` — Где тема сейчас: сессия, модель, усилие, идущие ходы. Ничего не меняет.
- `/sessions` — Сессии этой темы. /sessions показывает последние и id, который можно скопировать; /sessions <id> продолжает старую сессию здесь же. /new начинает новую, старая остаётся на диске.
- `/rewind` — Откат — одна команда с тремя словами. /rewind 2 убирает два последних хода, чтобы сформулировать иначе: сначала карточка того, что уйдёт, режет только кнопка; /rewind undo возвращает. /rewind fork [n] копирует сессию в том виде, каким она была n ходов назад, и переводит тему на копию — ничего не отрезается. /rewind branches показывает копии, нажатие переключает.
- `/profile` — Профиль, на котором идёт тема, и как его сменить: /profile <имя>, /profile new.
- `/compact` — Где происходит сжатие контекста, с каким порогом работает эта установка и что здесь работает вместо него: /new.
- `/card` — Карточка хода — это сообщение, которым заканчивается каждый ход. `/card` открывает её строки кнопками: время, скорость, мысли, шаги, контекст, стоимость, кэш, рассуждение. Выбор свой у каждой темы и действует со следующего хода.

### Модель, цены, подмена

- `/model` — Одна команда для модели этого профиля: голый /model рисует все маршруты кнопками — провайдер и модель вместе, потому что одно имя модели могут отдавать разные эндпоинты, — а /model <провайдер>/<модель> переключает без кнопок. Нажатие на карточке меняет ЭТУ тему; переключатель над списком меняет весь профиль разом и всегда говорит, что именно сделает нажатие. /model <маршрут> all задаёт значение по умолчанию для всех тем — это то, что нужно, когда у эндпоинта кончились деньги и цепочке fallback надо начинать с другого места. /model <id> both ещё и меняет профиль desktop.
- `/effort` — Насколько глубоко модель думает перед ответом: /effort high.
- `/prices` — Цены моделей в работе и во что обходится текущая модель на токенах этой темы.
- `/cost` — Сколько потратила эта сессия: токены, попадания в кэш и сумма, с указанием источника цен. /cost читает каталог с диска, /prices — тот, кто его обновляет.
- `/thoughts` — Рассуждения последнего хода: текстом, файлом или выкл.
- `/fallback` — Цепочка подмены: на какие маршруты переходит упавший ход, в каком порядке, и что включает переход. /fallback показывает нумерованный список кнопками; /fallback test спрашивает каждый маршрут напрямую.
- `/endpoint` — Эндпоинты, до которых дотягивается этот профиль, и добавление своего без хода модели: /endpoint list, /endpoint add <id> <https://url/v1> <KEY_ENV> [модель,модель], /endpoint rm <id>. Вводится только имя переменной с ключом — сам ключ живёт в окружении. Новая модель сразу появляется в /model кнопкой.
- `/load` — Насколько занят этот компьютер: процессор, память, диск и сколько слотов ходов занимает мост. Ограничитель придерживает новый ход, пока машина вне лимитов, чтобы человек за тем же компьютером не оказался в заморозке.

### Агенты и права

- `/agents` — Агенты и субагенты: кто настроен, на какой модели, кого реально запускали.
- `/crew` — Именованный набор «модель + права + пресет» для этой темы: /crew use <id> включает целиком, /crew off возвращает профиль, /crew new|copy|rm и /crew model <v> правят набор.
- `/preset` — Пресет агента (персона и инструменты) профиля: /preset <id>.
- `/plan` — Режим плана в теме: /plan включает и выключает; план приходит до любых правок, потом карточка «Одобрить».
- `/permissions` — Песочница и пресет подтверждений профиля.

### Расписания и очередь

- `/jobs` — Что мост делает сейчас: активные ходы и очередь за ними.
- `/remind` — Одно напоминание: /remind +15m текст или /remind 09:30 текст.
- `/every` — Одно повторяющееся расписание: /every 09:00 текст каждый день в это время запускает текст как обычный ход. /every list показывает расписания этого чата, /every rm 2 убирает одно. Срабатывает, только пока мост запущен; время, пропущенное при выключенном мосте, сработает один раз при следующем запуске, а не по разу за каждый пропущенный день.

### Расширения

- `/skills` — Установленные скиллы или текст одного.
- `/plugins` — Список плагинов и изменения: /plugins, /plugins add|remove|disable|enable <id>.
- `/mcp` — MCP-серверы профиля: /mcp списком, /mcp <имя> одним, /mcp add <имя> <url> и /mcp rm <имя>. Инструменты сервера вызывает агент — карточка их только называет.
- `/soul` — Файл персоны профиля: показать или задать.

### Версии моста

- `/update` — Какая версия моста работает, что есть на npm, и режим уведомлений: /update, /update on|off|confirm|auto.
- `/subscribe` — Сообщается ли о нас как о пользователе плагина: /subscribe on|off.
- `/dsh` — Какой DSH установлен, какой публикует npm и проверяли ли на нём этот мост. /dsh update ставит опубликованный; перезапуск — уже сам.

### Переключатели чата

- `/settings` — Все переключатели одной карточкой: сверху — что это за страница и что значит каждая строка, снизу — кнопки в том же порядке, ● отмечает текущее значение. Страницы: /settings (ответы и вид чата), /settings agent (модель, усилие, права), /settings updates (версии), /settings health (проверки и журналы). Нажатие применяет сразу и перерисовывает карточку, «Готово» убирает её.
- `/lang` — Язык бота в теме: /lang en|ru|zh.
- `/reasoning` — Заметки о ходе работы: выкл, в карточке прогресса или отдельными сообщениями в чат — /reasoning off|card|chat.
- `/pin` — Держит карточку прогресса закреплённой на время хода, чтобы часы и шаги были в одно касание — /pin on|off.

### Панели и справка

- `/menu` — Панель: каждая работа кнопкой. Нажатие выполняет команду, карточка остаётся, а ответ приходит под ней.
- `/help` — Этот список. /help <команда> объясняет одну команду.

### Проверки и журналы

- `/doctor` — Проверяет установку: мост, сеть, диск, плагины, сессию. С него начинают, когда что-то сломалось.
- `/logs` — Лог моста: /logs, /logs 100, /logs errors, /logs file.
- `/report` — Отчёт об ошибке из того, что мост уже знает, с вырезанными секретами и домашними путями: /report. В группе приходит путь к файлу вместо лога.
- `/app` — Приложение DSH, не мост: /app restart confirm.
- `/restart` — Перезапускает мост: /restart confirm. Приложение — /app.

Эти имена тоже работают — если палец промахнулся или привычка осталась. В /help они не рекламируются: у каждой работы одно имя.

## 中文

本页与 `/help` 用同一份代码生成：列表、分组和说明与机器人完全一致。/help 用话题的语言回答，这里三种语言都在。

### 文件与话题的项目

- `/start` — — 欢迎卡片：这个机器人是什么，以及开始用的三条命令。有人打开机器人时 Telegram 会发送它。
- `/cd` — 把话题绑定到项目文件夹：/cd my-app。之后本话题的轮次都在那里执行。
- `/ls` — [目录] —— 以按钮列出本话题的目录，目录在前。点目录进入，点文件查看。`/ls <文件>` 直接打开文件。
- `/view` — <文件>[:行号] —— 带行号显示文件，每次四十行，「更多」翻页。`文件:412` 直接跳到第 412 行。只读：改文件用 /edit，/diff 可以只回退某一回合改过的其中一段。
- `/edit` — <文件>:<行号> —— 直接在聊天里改文件的行。你指定行，下一条消息发新内容，随后出现带「应用」和「取消」的差异；只有按下「应用」才会写入，而且只有这些行仍与差异中显示的一致时才会写。
- `/new` — 在本话题开始新会话。旧的留在磁盘上，用 /sessions <id> 回来。
- `/stop` — 停止本话题正在进行的轮次（进度消息下的按钮效果相同）。
- `/send` — 把项目中的文件发到聊天：/send report.pdf。
- `/seed` — 为空话题写入首段文本并置顶，适用于机器人加入前创建的话题。
- `/diff` — 这个话题里这一回合改了什么，一个 hunk 一个 hunk 地看。每个 hunk 有两个按钮：解释它，或者只回退它。`/diff stat` 只看文件列表。
- `/find` — <文字> [路径] —— 在话题目录里按字面查找，结果以按钮显示，点开即跳到该行。二进制或过大的文件会被跳过并计数。

### 目标与任务

- `/goal` — 用一行说明本话题的目标：/goal <文本>、/goal done。任务在其下。
- `/tasks` — 带按钮的任务清单：点一下即完成或取消完成，卡片原地重绘。

### 会话：状态、回退、副本

- `/status` — 本话题的状态：会话、模型、力度、进行中的轮次。不改变任何东西。
- `/sessions` — 本话题的会话。/sessions 列出最近几个和可复制的编号；/sessions <id> 就在这里继续较早的会话。/new 开始新的，旧的留在磁盘上。
- `/rewind` — 回退只有一条命令、三种说法。/rewind 2 去掉最后两轮以便换种说法：先显示将移除内容的卡片，只有按按钮才裁切；/rewind undo 可恢复。/rewind fork [n] 把会话复制成 n 轮前的样子并把本话题切到副本，不切断任何东西。/rewind branches 列出副本，按一下就切换。
- `/profile` — 本话题使用的配置档，以及如何更换：/profile <名称>、/profile new。
- `/compact` — 上下文压缩发生在哪里、本机用的阈值是多少，以及在这里真正有效的那件事：/new。
- `/card` — 回合卡片是每个回合结束时的那条消息。`/card` 把它的各行做成按钮：耗时、速度、思路、步骤、上下文、费用、缓存、推理。每个主题各有一套，从下一回合生效。

### 模型、价格、替补

- `/model` — 本配置档模型的一条命令：直接 /model 把每条线路画成按钮 —— 提供方与模型一起选，因为同一个模型名可能由多个端点提供 —— 也可以用 /model <提供方>/<模型> 直接切换。点卡片上的线路只改本话题；列表上方的开关一次改整个配置档，并且始终写着这一下会改哪一边。用 /model <线路> all 设定所有话题跟随的默认 —— 当某个端点没钱了、fallback 链路必须从别处开始时，就用它。加 both 还会改 desktop 配置档。
- `/effort` — 模型回答前的思考深度：/effort high。
- `/prices` — 在用模型的价格，以及当前模型花掉本话题令牌的费用。
- `/cost` — 本会话花了多少：令牌、缓存命中与合计，并注明价格来源。/cost 读取本地目录，/prices 负责更新它。
- `/thoughts` — 上一轮的推理：文本、文件或关闭。
- `/fallback` — 故障切换链：失败的一轮会切到哪些线路、按什么顺序、什么情况才算切换。/fallback 用按钮显示编号列表；/fallback test 直接询问每条线路。
- `/endpoint` — 本配置档可以访问的端点，以及不经过模型回合直接添加：/endpoint list、/endpoint add <id> <https://url/v1> <KEY_ENV> [模型,模型]、/endpoint rm <id>。只输入存放密钥的变量名 —— 密钥留在环境里。新模型会以按钮出现在 /model。
- `/load` — 这台电脑有多忙：处理器、内存、磁盘，以及网桥占用了多少回合槽。限制器会在机器超出限制时暂缓新回合，让同一台电脑前的另一个人不至于被卡住。

### 智能体与权限

- `/agents` — 智能体与子智能体：配置了谁、用什么模型、实际启动了谁。
- `/crew` — 本话题的命名组合「模型 + 权限 + 预设」：/crew use <id> 整套启用，/crew off 回到配置档，/crew new|copy|rm 与 /crew model <v> 编辑组合。
- `/preset` — 配置档的智能体预设（人格与工具）：/preset <id>。
- `/plan` — 本话题的计划模式：/plan 打开或关闭，先给计划再改动，然后出现「批准」按钮。
- `/permissions` — 配置档的沙箱与确认预设。

### 定时与队列

- `/jobs` — 桥接器当前在做什么：进行中的轮次与排队的。
- `/remind` — 一条提醒：/remind +15m 文本 或 /remind 09:30 文本。
- `/every` — 一个重复的定时任务：/every 09:00 文本 每天这个时间把文本当成普通轮次执行。/every list 显示这个聊天里的定时任务，/every rm 2 删除一个。只在桥接运行时触发；停机期间错过的时间会在下次启动时补触发一次，而不是每错过一天补一次。

### 扩展

- `/skills` — 已安装的技能，或某个技能的内容。
- `/plugins` — 插件列表与修改：/plugins、/plugins add|remove|disable|enable <id>。
- `/mcp` — 配置档的 MCP 服务：/mcp 看列表，/mcp <名称> 看一个，/mcp add <名称> <url>，/mcp rm <名称>。服务的工具由 agent 调用，卡片只报名字。
- `/soul` — 配置档的人格文件：查看或设置。

### 桥的版本

- `/update` — 你运行的桥接版本、npm 上的版本，以及更新通知模式：/update、/update on|off|confirm|auto。
- `/subscribe` — 是否公开本安装为该插件的使用者：/subscribe on|off。
- `/dsh` — 已安装的 DSH、npm 上的最新版本，以及桥是否在该版本上验证过。/dsh update 安装最新版，重启由你决定。

### 聊天开关

- `/settings` — 所有开关在一张卡片上：上方说明这页是做什么的、每行是什么意思，下方按钮就是同一份清单、同样的顺序，● 标出当前取值。分页：/settings（回答与聊天）、/settings agent（模型、力度、权限）、/settings updates（版本）、/settings health（检查与日志）。一按就生效并重画卡片，点「完成」收起。
- `/lang` — 本话题中机器人的语言：/lang en|ru|zh。
- `/reasoning` — 工作记录：关闭、放在进度卡片里，或作为消息发到聊天——/reasoning off|card|chat。
- `/pin` — 让进度卡片在本次运行期间保持置顶，时间和步骤一按就到——/pin on|off。

### 面板与帮助

- `/menu` — 面板：每项工作一个按钮。点击执行命令，卡片留着，回答出现在它下面。
- `/help` — 这个列表。/help <命令> 解释单个命令。

### 检查与日志

- `/doctor` — 检查安装：桥接、网络、磁盘、插件、会话。出问题先跑它。
- `/logs` — 桥接日志：/logs、/logs 100、/logs errors、/logs file。
- `/report` — 用桥接已掌握的信息生成的问题报告，发送前已去除密钥与主目录路径：/report。在群里只回复文件路径，不发日志。
- `/app` — DSH 桌面应用，不是桥接：/app restart confirm。
- `/restart` — 重启桥接：/restart confirm。桌面应用用 /app。

### 旧写法

这些名字同样可用——手指滑了或习惯还在。 /help 不宣传它们：一件事只有一个名字。

`/models` → `/model` · `/plugin` → `/plugins` · `/agentset` → `/crew` · `/task` → `/tasks` · `/fork` → `/rewind` · `/branches` → `/rewind` · `/resume` → `/sessions` · `/version` → `/update`

行内提示：在任意聊天输入 @bot rew，会列出以 rew 开头的命令。请在 @BotFather 里用 /setinline 打开一次，否则 Telegram 不会发送行内查询。
